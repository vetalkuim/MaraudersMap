# Карта мародёров — живые обои

Живые обои для Android 8.0+ (API 26), Kotlin, без сторонних зависимостей.

## Фон
Три варианта пергамента (`app/src/main/res/drawable-nodpi/`):

| Вариант | Файл |
|---|---|
| Сложенная карта (широкий сгиб) | `bg_fold_wide.webp` |
| Разглаженная карта (тонкий сгиб) | `bg_fold_thin.webp` |
| Ровный пергамент | `bg_plain.webp` |

Четвёртый вариант — «Своя картинка»: пользователь выбирает изображение из галереи
(Photo Picker на Android 13+, системный выбор файлов на старых версиях). Картинка
копируется во внутреннее хранилище приложения — уменьшенной до 2560 px по длинной
стороне и с учётом поворота из EXIF, — поэтому доступ к исходному файлу не нужен.

Плюс режим «Анимация раскрытия» (по умолчанию): при каждом появлении обоев
пергамент плавно переходит широкий сгиб → тонкий сгиб → ровный лист (~1.5 с),
после чего перерисовка останавливается, чтобы не тратить батарею.

Фон масштабируется по принципу center-crop под любой экран.

## Слои
Обои рисуются слоями снизу вверх:

| Слой | Что | Настройка |
|---|---|---|
| 0 | Пергамент (фон) | варианты выше |
| 1 | Нарисованная карта | «Без карты», «Карта мародёров» (по умолчанию, `res/raw/map_hogwarts.svg`) или свой файл SVG/PNG |

Карта вписывается в экран целиком с небольшими полями и на Android 10+ накладывается
режимом «умножение» — чернила ложатся на пергамент, а белый фон PNG-рисунка не перекрывает бумагу.
В режиме «Анимация раскрытия» карта проступает чернилами после разворота листа.

Свой файл выбирается в настройках и копируется во внутреннее хранилище приложения.
SVG разбирается встроенным парсером (`SvgImage`, `SvgPathParser`): фигуры, группы, `transform`,
сплошные заливка и обводка; градиенты, текст, `use` и клипы пропускаются.
Растровые файлы больше 4096 px по стороне уменьшаются при загрузке.

## Структура
- `MapWallpaperService` — `WallpaperService` и движок: видимость, поверхность, цикл кадров.
- `MapRenderer` — отрисовка слоёв; новые слои (имена, следы) добавляются поверх карты в `draw()`.
- `MapBackground` / `MapPrefs` — варианты фона, слоя карты и их хранение.
- `CustomBackground` — импорт и загрузка своей картинки для фона.
- `MapLayer` / `MapLayers` — слой карты: загрузка встроенной карты или своего SVG/PNG.
- `SvgImage` / `SvgPathParser` — SVG без сторонних библиотек.
- `SettingsActivity` — выбор фона и карты с предпросмотром и кнопка установки обоев.
