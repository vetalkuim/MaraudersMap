# Карта мародёров — живые обои

Живые обои для Android 8.0+ (API 26), Kotlin, без сторонних зависимостей.

## Фон
Четыре варианта пергамента (`app/src/main/res/drawable-nodpi/`):

| Вариант | Файл |
|---|---|
| Сложенная карта (широкий сгиб) | `bg_fold_wide.webp` |
| Разглаженная карта (тонкий сгиб) | `bg_fold_thin.webp` |
| Ровный пергамент | `bg_plain.webp` |
| Старый пергамент с пятнами (1080×2340, генерируется `tools/generate_parchment.py`) | `bg_parchment.webp` |

Плюс режим «Анимация раскрытия» (только по первым трём кадрам) (по умолчанию): при каждом появлении обоев
пергамент плавно переходит широкий сгиб → тонкий сгиб → ровный лист (~1.5 с),
после чего перерисовка останавливается, чтобы не тратить батарею.

Фон масштабируется по принципу center-crop под любой экран.

## Структура
- `MapWallpaperService` — `WallpaperService` и движок: видимость, поверхность, цикл кадров.
- `MapRenderer` — отрисовка; новые слои (имена, следы, комнаты) добавляются поверх фона в `draw()`.
- `MapBackground` / `MapPrefs` — варианты фона и их хранение.
- `SettingsActivity` — выбор фона с предпросмотром и кнопка установки обоев.

## Сборка
```
./gradlew assembleDebug
```
